# دستیار هوش مصنوعی شخصی

سیستم دستیار هوشمند با هستهٔ پایتون و رابط کاربری وب.

## 🏗 معماری

```
├── src/personal_ai/    هستهٔ اصلی (Python)
├── apps/web/           رابط کاربری (TypeScript)
├── models/             مدل‌ها
├── scripts/            اسکریپت‌های کمکی
├── tests/              تست‌ها
├── docs/               مستندات
└── requirements/       وابستگی‌ها
```

## 🛠 تکنولوژی

`Python` `TypeScript` `Web UI`

## 🚀 راه‌اندازی

```bash
git clone https://github.com/MiadYazdi/personal-ai.git
cd personal-ai
pip install -r requirements/requirements.txt
```
